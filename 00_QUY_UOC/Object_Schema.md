# Knowledge Object Schema

## Required fields

- **ID:** Stable identifier for the canonical object.
- **Title:** Concise, domain-neutral label.
- **Description:** One main claim or reusable method.
- **Evidence:** What supports the object; cite evidence or mark as inferred.
- **Related Nodes:** Stable references to connected objects.

## Preserved metadata

- **FACT / INFERENCE / UNKNOWN:** Epistemic status, kept distinct.
- **Confidence:** High / Medium / Low with rationale; not a probability.
- **Status:** Candidate, reviewed, approved, or retired only when supported by a recorded review.
- **Source:** Authorized source document and relevant section/ID.

**FACT:** The seed schema requires ID, title, description, evidence, and related nodes; its confidence convention is qualitative.  
**INFERENCE:** Status and provenance fields should remain attached when an object is copied or linked.  
**UNKNOWN:** Target platform validation, versioning, and retirement requirements.
