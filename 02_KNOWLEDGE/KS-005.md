- **ID:** KS-005
- **Title:** Do not turn forecast into history
- **Description:** Label confirmed incidents, modeled error conditions, forecast risks, and unknowns separately. Record root cause only when evidence supports it.
- **Evidence:** Framework F-05, graph node K-010, and failure-analysis candidates.
- **Related Nodes:** K-001, K-009, K-010, K-011, K-014
- **Confidence:** High

**FACT:** The source set warns against representing modeled risks as confirmed incidents.  
**INFERENCE:** Maintain distinct records and evidence status for each category.  
**UNKNOWN:** Events beyond the source set and the destination incident lifecycle.
